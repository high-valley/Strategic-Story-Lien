灯火の戦旗 — iPhone対応・ターン制タクティカルRPG試作
===================================================

【含まれるファイル】
index.html : HTML/CSS/JavaScriptが1ファイルにまとまったゲーム本体

【遊び方】
1. 青色の味方をタップ
2. 青い移動マスをタップ（その場をタップすると移動せず行動）
3. 攻撃可能な敵が赤く表示されるので、タップで攻撃
4. 攻撃できなければ「待機」を押す
5. 「ターン終了」で敵の行動が開始される
6. 章ごとの勝利条件を満たせばクリア（第一章：敵の全滅／第二章：首領ガルドの撃破）
7. 章の始まりと終わりに会話シーンがあります（タップで進む／スキップ可）

【基本ルール】
- 第一章「霧の谷の遭遇」：味方3名、敵4名
- 第二章「灯台砦の夜襲」：新たな仲間ソラ（斧）が加わり味方4名、敵6名。
  川を渡る2本の橋と、首領が守る砦が舞台
- 剣 > 斧 > 槍 > 剣 の武器相性
- 弓は2マス離れた敵に攻撃可能
- 森・砦・山では被ダメージが軽減される（山は移動コスト3）
- 到達した章はブラウザに保存され、次回はその章から再開
- 味方全滅でゲームオーバー

【iPhoneから遊ぶ】
GitHubに新規リポジトリを作り、index.htmlをアップロードして、
Settings > Pages > Deploy from a branch > main / (root) で公開すると、
iPhoneのSafari/Chromeからタッチで遊べます。

【開発・改造】
外部ライブラリ・画像・通信・ビルドは不要。
index.htmlをエディタで編集するだけでルールやグラフィックを変更できます。
ゲームデータ（マップ・ユニット・会話）は配列 CHAPTERS に章ごとにまとまっています。
章を増やすときは CHAPTERS に要素を追加してください。

商用/公開に向けて、キャラクター画像、戦闘アニメーション、育成・セーブ、
アクセシビリティ等は今後の拡張項目です。

ファイアーエムブレムの固有キャラクター、マップ、素材、音源は使用していません。
